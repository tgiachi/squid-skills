# Squid Interface Docs

Add `///` XML documentation to C# interfaces and public interface members only.

## Scope

- Default to every `.cs` file under the current working directory containing an interface declaration.
- If the user provides a path or glob, restrict scanning to it.
- Skip `bin/`, `obj/`, `node_modules/`, `.git/`, generated files, and files with `<auto-generated>`.
- Do not document classes, structs, records, enums, delegates, or implementation members.
- Do not commit.

## Discovery

Use `rg` first:

```bash
rg -n --glob '*.cs' --glob '!bin/**' --glob '!obj/**' --glob '!node_modules/**' \
  '\b(public|internal)\s+(partial\s+)?interface\s+I[A-Za-z0-9_]+'
```

For each candidate file, read the full file and locate every interface declaration plus every member inside the interface body: methods, properties, events, and indexers.

## Writing Rules

- Preserve existing documentation unless it is an empty stub such as `/// <summary></summary>`.
- Write concise XML docs that describe contract purpose, not the signature.
- Use present tense, third person: "Loads the asset", "Gets the current state".
- Avoid filler such as "This interface is responsible for".
- Match terminology from nearby code.
- Do not invent behavior. If unclear, add `// TODO: clarify behavior with author` above the XML doc and write the minimal accurate summary.
- Preserve indentation and line endings.

## Templates

Interface:

```csharp
/// <summary>
/// Provides access to project assets.
/// </summary>
public interface IAssetProvider
{
}
```

Method:

```csharp
/// <summary>Loads the asset identified by the specified key.</summary>
/// <param name="key">Key that identifies the asset to load.</param>
/// <param name="cancellationToken">Token used to cancel the asynchronous operation.</param>
/// <returns>The loaded asset.</returns>
Task<Asset> LoadAsync(string key, CancellationToken cancellationToken);
```

Property:

```csharp
/// <summary>Gets the current connection state.</summary>
ConnectionState State { get; }
```

Event:

```csharp
/// <summary>Raised when the connection state changes.</summary>
event EventHandler<ConnectionStateChangedEventArgs> StateChanged;
```

## Edit Workflow

1. Build a per-file list of missing docs.
2. Apply focused edits with `apply_patch`.
3. Re-read edited files.
4. Run `dotnet build` when a solution or project is present. If multiple solutions exist, choose the one matching the edited tree.
5. Report files scanned, interfaces documented, members documented, untouched files, and unclear items where a TODO was left.
